## 🚀 如何使用

### 1. 直接使用演示腳本
```bash
Rscript AmPEP30_Demo.R
```

### 2. 在 R 中調用預測函數
```r
# 載入演示腳本
source("AmPEP30_Demo.R")

# 預測序列
result <- predict_peptide("GIGKFLHSAKKFGKAFVGEIMNS")
print(result)
```

### 3. 命令行預測
```bash
# 創建 FASTA 文件
echo ">test_sequence
GIGKFLHSAKKFGKAFVGEIMNS" > test.fasta

# 執行預測
Rscript RF-AmPEP30.R test.fasta output.txt

# 查看結果
cat output.txt
```
